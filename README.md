# Restaurant Management System

A full-stack web application for managing restaurant operations, built with Flask and Vue.js.

## Overview

This project provides a web-based interface for restaurant administration, including menu and order management.

## Features

- Admin authentication
- Restaurant dashboard
- Menu management
- Order management
- Order notifications
- PDF report generation
- Responsive web interface
- Flask REST API
- Vue.js frontend

## Tech Stack

### Frontend
- Vue.js
- JavaScript
- Vite
- Tailwind CSS

### Backend
- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login

### Database
- MySQL / SQLAlchemy
